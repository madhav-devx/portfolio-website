# Personal Portfolio Website

A responsive one-page developer portfolio made with HTML, CSS and JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Replace the placeholder profile and links before publishing.

## Customize
Search in `index.html` and replace:
- `Your Name`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`
- `your.email@example.com`
- Resume file at `assets/resume.pdf`
- Project repository / live demo links
- Skills and project details to match your real experience

## Publish
This is a static website and can be hosted on GitHub Pages, Netlify, or Vercel.
For GitHub Pages, upload the site files to a repository, then open Settings → Pages and select the `main` branch and `/ (root)` folder.
